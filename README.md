## Questions dans Supabase

Le jeu garde les salons multijoueurs dans Firebase et charge les questions depuis
Supabase. Les anciens fichiers JSON ont été retirés du site ; le CSV local
`questions-import.csv` contient une copie d'import et est ignoré par Git.

### 1. Créer le projet et la table

1. Crée un projet sur [supabase.com](https://supabase.com/) et attends qu'il soit prêt.
2. Dans le projet, ouvre **SQL Editor**, crée une nouvelle requête, colle et exécute :

```sql
create table public.questions (
  id bigint generated by default as identity primary key,
  theme text not null,
  question text not null,
  answers jsonb not null,
  difficulty integer not null default 1
);

alter table public.questions enable row level security;

create policy "Questions lisibles par les joueurs"
on public.questions
for select
to anon, authenticated
using (true);
```

La règle autorise la lecture des questions par le jeu, mais pas leur modification
depuis le navigateur. Gère les questions avec le tableau de bord Supabase.

### 2. Importer les questions dans Supabase

1. Dans Supabase, ouvre **Table Editor** puis la table `questions`.
2. Choisis **Insert** / **Import data from CSV** (l'intitulé peut varier), puis
   sélectionne `questions-import.csv` à la racine du projet.
3. Vérifie l'association des colonnes `theme`, `question`, `answers` et
   `difficulty`. Ne mappe pas la colonne `id` : la base la génère.
4. Lance l'import et vérifie que les lignes apparaissent dans la table.

Les noms de thème attendus sont les noms des fichiers sans `.json` :
`art`, `cinema`, `geographie`, `histoire`, `jeuxvideo`, `musique`, `science` et
`sport`.

### 3. Connecter le jeu à Supabase

1. L'URL et la clé publique `publishable` sont configurées dans
   `js/questions.js`. Cette clé est faite pour être utilisée dans le navigateur ;
   **n'utilise jamais** une clé `secret` ou `service_role` dans le site.
2. Publie le site GitHub Pages avec ces changements.
3. Crée une partie et vérifie que les questions se chargent.

Pour ajouter une question, tu peux directement ajouter une ligne dans **Table
Editor** ; `answers` doit être un tableau JSON, par exemple
`["Réponse 1", "Autre formulation"]`. Pour un ajout groupé, crée un CSV qui ne
contient que les nouvelles lignes avant de l'importer. Réimporter le catalogue
entier créera des doublons.

Le forfait gratuit Supabase comporte des quotas et certaines limites (par
exemple la mise en pause de projets inactifs) : il ne garantit pas un usage
illimité ou gratuit à vie. Les questions et réponses téléchargées par le jeu
restent consultables par les joueurs dans leur navigateur ; cette migration les
retire du dépôt/site, mais ne les rend pas secrètes.

## Firebase pour les salons

Firebase Realtime Database reste utilisé pour les parties en direct. Active
**Authentication → Sign-in method → Anonymous**, puis publie les règles locales
de `database.rules.json` dans **Realtime Database → Règles**. Les fichiers
`firebase.json` et `database.rules.json` sont exclus de Git par `.gitignore`.
